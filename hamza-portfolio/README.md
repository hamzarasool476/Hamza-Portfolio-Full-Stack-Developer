# Hamza Ghulam Rasool — Animated Portfolio

A responsive, animation-rich portfolio website built with plain HTML, CSS, and JavaScript. No build step or framework install is required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use a local static server such as VS Code Live Server.

## Included
- Responsive layout and mobile navigation
- Scroll reveal animations and reading progress bar
- Animated marquee, orbit details, floating cards, and portrait parallax
- MERN stack, GitHub AI, services, and three existing portfolio projects
- Email and phone links
- Reduced-motion accessibility support
